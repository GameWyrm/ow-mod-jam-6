# HOTEL PENUMBRA

It's time for a nice, long vacation at the end of time. The accommodations are so good, you might end up staying forever! Meet new friends! Swim in our pool! Travel through time!

To start this mod, you'll need to make a visit to the dear old Eye. Make sure you aren't using any kind of cheats to skip a part of the journey, because you won't be able to appreciate the scenic route that way! You'll also probably not arrive properly.

Made by Hearth's Jammers for the sixth Outer Wilds modding jam.
